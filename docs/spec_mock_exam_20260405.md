# 仕様書: 本番模擬試験モード

## 概要
実際の登録販売者試験と同じ形式・時間・配点で120問を解ける模擬試験モード。
試験当日の緊張感を事前に体験し、合否判定・弱点分析まで一連でできる。

## ユーザーストーリー
- 受験生として、本番と同じ条件で自分の実力を確認したい
- 受験生として、試験後に「どのカテゴリが弱いか」をすぐ把握したい
- 受験生として、合格/不合格の判定結果を見てモチベーションを維持したい

## 受け入れ条件
- [ ] ホーム画面から「模擬試験」に入れる
- [ ] 開始前に「120問・120分・本番形式」の説明画面が表示される
- [ ] 試験中は常に残り時間（カウントダウン）が表示される
- [ ] 120問を5カテゴリの正規配分で出題（40:20:20:20:20）
- [ ] 試験中は正解・不正解フィードバックを表示しない（実試験と同じ）
- [ ] 問題番号一覧から任意の問題へジャンプできる
- [ ] 未回答の問題数が常に確認できる
- [ ] 時間切れまたは「提出」ボタンで採点画面へ移行する
- [ ] 採点結果：総得点・合否判定（70%以上かつ各章35%以上）が表示される
- [ ] カテゴリ別正答率がグラフで表示される
- [ ] 間違えた問題を一覧レビューできる
- [ ] 試験結果がSRS学習記録にも反映される

## 合否判定ロジック（実試験準拠）
```
合格条件：
  1. 総得点 ≥ 84点（120点満点の70%）
  2. 各カテゴリの得点 ≥ そのカテゴリ満点の35%（都道府県により40%の場合あり）

カテゴリ配分：
  第1章 医薬品に共通する特性と基本的な知識  20問
  第2章 人体の働きと医薬品                  20問
  第3章 主な医薬品とその作用                40問
  第4章 薬事関係法規・制度                  20問
  第5章 医薬品の適正使用・安全対策          20問
```

## エッジケース
- 問題が120問未満の場合: 利用可能な問題数で実施し、配分比は維持する
- タブを閉じた場合: localStorageに進行状態を保存し、再開できる
- 時間切れ: 自動的に採点画面へ遷移する

## スコープ外
- 問題のシャッフル以外のランダム化オプション
- 複数回の試験結果の履歴比較
- タイマーの一時停止機能
