# 仕様書: Sprint 1 — クイズ基本機能 + キャラクター成長

## 概要
登録販売者試験合格を目指す女性ユーザーが、スマホで快適に過去問を解けるMVPを構築する。
学習継続のモチベーションを高めるキャラクター成長システムも初回から含める。

## ユーザーストーリー
- 受験生として、スキマ時間に1問から気軽に問題を解きたい
- 受験生として、正解・不正解がすぐわかり、解説も読めるようにしたい
- 受験生として、がんばるほどキャラが育つのが見えて、やる気が続くようにしたい

## 受け入れ条件（Acceptance Criteria）
- [ ] ホーム画面にキャラクター・合格期待値ゲージ・学習統計が表示される
- [ ] 「問題を解く」ボタンでクイズセッションが始まる
- [ ] 4択問題が表示され、選択肢をタップすると即座に正解・不正解がわかる
- [ ] 正解時は緑、不正解時は赤でフィードバックされ、正解の選択肢が強調表示される
- [ ] 解説文が表示される
- [ ] 「次の問題へ」でスムーズに次問に進める
- [ ] セッション（10問）完了後に結果画面が表示される
- [ ] 解答結果がローカルストレージに保存され、再起動後も残る
- [ ] 正解数に応じてキャラクターの経験値・ステージが増加する
- [ ] 合格期待値ゲージが学習進捗に連動して変化する

## データ仕様

### Question型
```typescript
{
  id: string,
  category: QuestionCategory,
  year: number,
  text: string,
  options: string[],  // 4択
  correctIndex: number,
  explanation: string,
  difficulty: 1 | 2 | 3
}
```

### QuestionRecord型（SRS）
```typescript
{
  questionId: string,
  interval: number,       // 次回出題までの日数
  easeFactor: number,     // 難易度係数
  nextReviewDate: string,
  totalAttempts: number,
  correctAttempts: number,
  lastResult: "correct" | "wrong"
}
```

## エッジケース・考慮事項
- 問題数が少ない場合（サンプル5問）: SESSION_SIZEを問題数に合わせて縮小する
- オフライン状態: ローカルデータのみで動作（APIは未使用）
- 画面回転: 縦向き固定（PWAマニフェストで制御）

## スコープ外（今回作らないもの）

- ユーザー登録・ログイン
- 詳細な統計画面（Sprint 3以降）
