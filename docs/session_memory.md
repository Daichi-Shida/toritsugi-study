## 2026-08-30 セッション（結果画面から元の問題を見返せるように・出題のランダム化）

妻からの2件の指摘に対応した。

### 1. クイック模擬試験の解説から元の問題を確認できない

**原因は2つ**
- 結果画面の見返しが `q.text`（設問文）と `explanation` しか出しておらず、
  ａ〜ｄの記述文と選択肢を出していなかった。解説は「ａ（正）…」と各記述を
  指しているので、記述文が無いと何の話か確認できない。
- 結果画面が表示と同時に `localStorage` の受験データを消していた。
  再読み込み・戻る→進むで結果ごと消え、`/mock-exam` に飛ばされていた。

**直した内容**
- `src/components/mock/QuestionReview.tsx`（新規）— 問題文・ａ〜ｄの記述文・
  穴埋め本文・全選択肢（◎正解／←あなたの答えの印つき）・解説をまとめて出す。
  正誤組み合わせ型の選択肢は「ａ 正　ｂ 誤 …」の1行に整形。
- 結果画面に「間違えた問題／全30問」の切り替えを追加（既定は間違えた問題）。
- `finishMockExam()` / `loadMockExamResult()` を新設し、採点結果を
  `toritsugi_mock_exam_result` に保存。結果画面は**読むだけ**にした。
  受験中のキー `toritsugi_mock_exam` は提出時に消す（再開ボタンを出さないため）。
- 模擬試験の開始画面に「前回の結果・解説を見る」を追加。

**ステータス進行への影響なし**
学習記録（SRS・学習セッション）の反映は従来どおり提出時の1回だけ。
結果画面は保存済みデータを読むだけなので、何度開いても二重計上されない。
実ブラウザで解答数・経験値・学習セッションが変化しないことを確認済み。

### 2. 章別学習で同じ問題ばかり出る

**原因**: `src/app/quiz/page.tsx` が due → weak → rest を並べて**先頭10問**を
取るだけだった。並び順は問題プールの並び（令和7年度東京→令和6年度東京…）の
ままで、しかも間違えた問題は `interval=0` でずっと期限切れのまま先頭に残る。
つまり章を開くたびに毎回まったく同じ10問が同じ順で出ていた。

**直した内容**: `src/lib/questionPicker.ts`（新規）に出題ロジックを切り出した。
1. 問題を4層に分ける（due=復習期限切れ / weak=正答率6割未満 / fresh=未学習 / known=定着）
2. 層ごとに割当（章別・弱点は due4:weak3:fresh2:known1）を配り、**層の中はシャッフル**
3. 割当が埋まらない分は due を**最後**に回して補う
   （復習対象が10問しか無い時に毎回その10問で埋まるのを防ぐ）
4. 直近80問に出した問題は層の後ろへ（`toritsugi_recent_questions`）
5. 似た問題を同じ回に入れない（文字3-gramのJaccard>0.40）
   — 過去問は年度・ブロックをまたいで同じ論点がほぼ同じ文面で出るため。
   しきい値は実プール全ペアの実測で決めた（無関係な組は中央値0.05・99%点0.16、
   年度違いの同一論点は0.6〜0.77。0.40で弾かれるのは全ペアの0.07〜0.52%）
6. 模擬試験の抽選も `sort(() => Math.random() - 0.5)`（偏るシャッフル）をやめ、
   Fisher–Yates ＋ 似た問題の排除に変更

学習記録には一切触れないので、章別正答率・達成度の数字は動かない。

### 3. 模擬試験でもキャラクターが育つように

これまで模擬試験は**学習記録（正誤）だけを保存し、経験値と合格期待値を更新して
いなかった**ため、120問解いてもキャラが1ミリも育たなかった。

- 提出時に `calcExperience(isCorrect, difficulty)` を全問分合計して加算する。
  章別学習とまったく同じ計算（正解 10×難易度 / 不正解・未回答 2×難易度）。
  → クイック30問で概ね +400〜600、本番120問で +1600〜3600。
- 合格期待値（ホームのゲージ）も提出時に再計算する。
- 結果画面に「獲得経験値」カード（キャラ名・+EXP・次のステージまでの残り）を追加。
  レベルアップした回は `LevelUpModal` の演出も出す。
- 演出は**最初に結果を見た時だけ**。`growth.celebrated` を立てて、
  結果画面を開き直したときは繰り返さない（加算も1回だけ）。

- `public/icon-192.png` / `public/icon-512.png` を生成
